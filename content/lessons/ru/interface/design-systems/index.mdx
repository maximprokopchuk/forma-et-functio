<DropCap>Д</DropCap>изайн-система — это не папка компонентов в Figma и не пакет в npm. Это договорённость команды о том, какими частями собирается продукт и какими правилами эти части соединяются: от значений цвета и отступа до того, кто имеет право добавить новый компонент в общую библиотеку. Component library описывает, что́ доступно; design system описывает, почему оно именно такое и как меняется. Между ними — слой токенов, контракт компонентного API, документация и governance, и каждый из этих слоёв решает свою задачу. Трек разбирает систему послойно — начинает с токенов, потому что без них верхние этажи не держатся: невозможно описать API кнопки, не договорившись, что такое «акцентный цвет». Дальше — компонентный API и slots, версионирование и контрибуция, связь с инженерным процессом.
